# AMZ LABS · GitHub Organization Profile

Este repositório contém a apresentação institucional exibida na página principal da organização [Amz-Labs](https://github.com/Amz-Labs).

- **Perfil público:** [`profile/README.md`](./profile/README.md)
- **Identidade visual:** [`profile/assets/amzlabs-logo.png`](./profile/assets/amzlabs-logo.png)

> O perfil institucional é público. Códigos de clientes, segredos, documentos contratuais e demais materiais sensíveis devem ser mantidos em repositórios privados com permissões apropriadas.

## Como publicar

1. Crie um repositório **público** com o nome exato `.github` na organização `Amz-Labs`.
2. Envie a estrutura deste pacote para a branch padrão (`main`).
3. Abra `https://github.com/Amz-Labs` e confira a apresentação na aba **Overview**.

## Próximos passos sugeridos

Crie repositórios privados próprios por produto/projeto/cliente, com acessos isolados por equipe e regras de revisão. Evite usar este repositório público para centralizar entregáveis de clientes.
